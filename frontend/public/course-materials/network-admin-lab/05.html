05 · File Classification Infrastructure

BÀI TẬP NHỎ 1. Phân biệt classification property, classification rule, file management task và file screening. 2. Thiết kế3 file mẫu: khớp điều kiện, không khớp, thiếu thông tin. Dự đoán thuộc tính phân loại cho từng file. THỰC HÀNH Dùng bản sao dữ liệu thử: tạo property/rule và chạy classification theo PDF; lập bảng expected/actual. Thử file expiration trên thư mục lab riêng, ghi đường dẫn đích và kiểm tra khả năng tìm lại file. Nộp rule, báo cáo chạy task và bảng file trước/sau. TỰ KIỂM TRA Đúng kiến thức và đầu ra: 4 điểm; xử lý biên/ngoại lệ: 2; kiểm thử có bằng chứng: 2; giải thích và nguồn: 2. Bài thực hành dùng luyện tập, chưa chấm sản phẩm tự động.
