07 · Kiểm thử API với Postman

BÀI TẬP NHỎ 1. Liệt kê method, URL, headers, body và response cần kiểm tra cho đăng ký khóa học. Vì sao chỉ kiểm tra HTTP200 là chưa đủ? 2. Phân biệt401,403,404 theo hợp đồng API của ứng dụng. Viết ý tưởng assertion cho response body và trạng thái lưu dữ liệu. THỰC HÀNH Trên API test của nhóm, xây collection ít nhất6 request/case: thành công, thiếu xác thực, lớp không tồn tại, lớp đóng, ghi danh trùng, dữ liệu sai kiểu. Xác nhận status/body theo hợp đồng API thực tế trước khi chạy. Dùng environment cho baseUrl; export collection và environment không có token thật, kèm kết quả Collection Runner nếu đã chạy. TỰ KIỂM TRA Đúng kiến thức và đầu ra: 4 điểm; xử lý biên/ngoại lệ: 2; kiểm thử có bằng chứng: 2; giải thích và nguồn: 2. Bài thực hành dùng luyện tập, chưa chấm sản phẩm tự động.
